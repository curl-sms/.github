# Security policy

## Reporting a vulnerability

Please report security issues privately to **help@curl-sms.com** with the subject `Security`. Do not open a public issue.

Include what you found, how to reproduce it and the impact you expect. We confirm receipt within two working days and keep you updated until the issue is fixed. We do not take legal action against good-faith research that follows these rules:

- Test only with your own account and test keys (`cs_test_…`). Test keys never send a real SMS.
- Do not access, change or delete other users' data.
- Do not run denial-of-service, spam or social-engineering tests.
- Give us reasonable time to fix the issue before you disclose it.

## Scope

- The curl-sms API and website at `https://curl-sms.com`, including the MCP server at `https://curl-sms.com/mcp`.
- The open-source repositories in the [curl-sms organization](https://github.com/curl-sms) (SDKs, GitHub Action, examples).

## Supported versions

Security fixes go into the latest release of each SDK and the GitHub Action. Please upgrade before reporting issues in older versions.
